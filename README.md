# 사내 비품 관리 시스템 (Office Supply Inventory Kiosk)

> **설치 없이 브라우저에서 바로 사용하는 사내 비품 재고 관리 키오스크 웹 애플리케이션**

---

## 📌 프로젝트 소개
사내 창고나 탕비실 등 공용 공간에서 비품을 꺼내갈 때, 복잡한 대장 작성 없이 누구나 **1초 만에 `[-1 가져감]` 버튼을 눌러 실시간 재고를 차감**할 수 있는 웹 기반 비품 관리 시스템입니다.

- **설치 불필요**: 단일 HTML 파일로 구성되어 Chrome, Edge 등 어떤 브라우저에서든 더블 클릭으로 바로 구동됩니다.
- **로컬 저장소 자동 동기화 (`localStorage`)**: 서버나 DB 없이도 웹 브라우저 내부에 데이터가 영구 보존됩니다.
- **애플 디자인 시스템 (`DESIGN-apple.md`) 적용**: SF Pro 타이포그래피, 액션 블루 알약 버튼, 18px 라운드 카드 등 깔끔하고 세련된 UI를 제공합니다.
- **재고 부족 자동 감지**: 최소 안전 재고 이하로 떨어진 품목을 감지하고, **[부족 품목]** 전용 탭에서 한눈에 모아볼 수 있습니다.

---

## 🚀 주요 기능

1. **원터치 수량 조절**:
   - `[-1 가져감]` 버튼: 비품 출고 및 즉각 수량 차감
   - `[+1 채워넣음]` 버튼: 비품 입고 및 수량 보충
2. **부족 품목 전용 필터 탭**:
   - 상단 필터 칩의 **[🚨 부족 품목 (N건)]** 탭을 누르면 발주가 필요한 품목만 즉시 선별
3. **보관 위치별 필터 및 실시간 검색**:
   - 2층 창고, 경영지원팀 캐비닛, 탕비실 하부장, 현장창고 등 위치별 카테고리 분류
   - 비품명 및 위치 실시간 검색 지원
4. **데이터 초기화**:
   - 15종 기본 비품 데이터로 언제든 원클릭 리셋 가능

---

## 💻 실행 방법

### 방법 1: 브라우저에서 바로 열기 (가장 간단)
- `비품재고관리.html` 파일을 더블 클릭하면 브라우저에서 즉시 실행됩니다.

### 방법 2: 로컬 개발 서버 실행
Node.js가 설치되어 있다면 내장 개발 서버를 실행할 수 있습니다:
```bash
node server.js
```
실행 후 브라우저에서 `http://localhost:8080/비품재고관리.html`로 접속합니다.
